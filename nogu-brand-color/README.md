# nogu-brand-color

nogu のブランドカラーパレットを提供する Claude Code スキル。

UI/Webデザイン、HTML/CSS生成、モックアップ作成など、視覚的な成果物を作るときに自動で参照されます。

## カラーパレット

### Service（UI基盤色）

| トークン名 | HEX | 用途 |
|-----------|-----|------|
| `service-bg` | `#F9F9F9` | 背景色 |
| `service-divider` | `#D5D5D8` | 罫線・ボーダー |

### Char（テキスト色）

| トークン名 | HEX | 用途 |
|-----------|-----|------|
| `char-main` | `#2C2E31` | メインテキスト |
| `char-sub` | `#787C87` | サブテキスト・補足情報 |
| `char-placeholder` | `#BBC5D1` | プレースホルダー・無効状態 |

### Brand（ブランド色）

| トークン名 | HEX | 用途 |
|-----------|-----|------|
| `brand-primary` | `#1A6AFF` | メインカラー |
| `brand-primary-sub` | `#D9E6FF` | メインカラー背景 |
| `brand-secondary` | `#FF557D` | アクセントカラー |
| `brand-secondary-sub` | `#FFD9E2` | アクセントカラー背景 |

## インストール

```bash
claude skill install /path/to/nogu-brand-color
```
